# Jordan's Home Assistant Add-ons

A Home Assistant add-on repository.

## Add this repository

In Home Assistant: **Settings → Add-ons → Add-on Store → ⋮ (top right) →
Repositories**, and paste this repository's URL.

## Add-ons in this repository

### [NEXRAD Radar Loop](./nexrad-radar-kdtx)

Self-hosted live NEXRAD weather radar loop — base reflectivity, storm-track
forecast lines, county/state/province map context — for any US radar site
and location. Built for embedding in a Lovelace `iframe` card. See its own
[README](./nexrad-radar-kdtx/README.md) for configuration and details.
